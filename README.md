# 问题单追踪器 (Issue Tracker)

在生产环境中汇总管理问题单的 Obsidian 插件，帮助团队高效追踪问题从发现到解决的全流程。

## 功能特性

- **问题单管理** — 创建、编辑、查看详情、删除问题单
- **订单分组** — 支持多个订单各自关联客户、型号、数量
- **进度追踪** — 待处理 / 处理中 / 已解决 / 已关闭 四种状态
- **生产影响标记** — 标记问题是否影响线上生产环境
- **筛选搜索** — 按关键字搜索，按状态和影响范围筛选
- **统计看板** — 顶部显示总数、各状态数量、影响生产数量
- **Markdown 导出** — 一键导出为结构化的汇总报告
- **Vault 文件夹同步** — 可选将问题单同步为独立的 Markdown 文件

## 数据字段

| 字段 | 说明 |
|------|------|
| 问题标题 | 简短概括问题 |
| 问题描述 | 详细描述问题的过程、现象和环境 |
| 发现人 | 谁发现了这个问题 |
| 相关人员 | 参与处理的同事 |
| 受影响订单 | 支持多个订单，每个订单独立关联客户、型号、数量 |
| 解决进度 | 待处理 / 处理中 / 已解决 / 已关闭 |
| 是否影响生产 | 勾选标记 |
| 解决方案 | 已采取或计划中的方案 |

## 使用方法

### 安装

1. 打开 Obsidian → **设置** → **第三方插件** → **社区插件**
2. 关闭 **安全模式**
3. 点击 **浏览**，搜索 "问题单追踪器"
4. 点击 **安装**，然后 **启用**

### 手动安装（社区上架前）

> **注意**：Release 页面有两个下载链接，请务必下载 **附件 ZIP**（`obsidian-issue-tracker-v*.zip`），不要下载 "Source code (zip)"。

1. 打开 [Releases 页面](https://github.com/emojia/obsidian-issue-tracker/releases)
2. 找到最新版本，在 **Assets** 下方点击下载 `obsidian-issue-tracker-v*.zip`
3. 将 ZIP 解压，得到 `main.js`、`manifest.json`、`styles.css` 三个文件
4. 将这三个文件放入你的 Obsidian Vault 的 `.obsidian/plugins/issue-tracker/` 目录（如文件夹不存在则手动创建）
5. 在 Obsidian 设置 → 第三方插件中启用

### 使用

1. 点击左侧栏的清单图标，或通过命令面板（`Ctrl+P`）输入 "打开问题单追踪器"
2. 点击 **新建问题单** 填写信息
3. 在表格中查看、筛选、编辑所有问题单
4. 点击 **导出 Markdown** 生成汇总报告

## 设置

在插件设置中可配置：

- **数据存储方式**：选择数据存储在插件目录或 Vault 文件夹
- **Vault 文件夹路径**：当选择 Vault 文件夹存储时，指定存放问题单 Markdown 文件的路径

## 开发

```bash
# 克隆仓库
git clone https://github.com/your-username/obsidian-issue-tracker.git

# 安装依赖
npm install

# 开发模式（监听文件变化）
npm run dev

# 构建
npm run build
```
